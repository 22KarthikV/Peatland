**Definitions and decisions:**
- A pixel counts only if both truth and prediction are not nodata (255). A prediction of 255 is treated as "no prediction" and dropped.
- Any other value outside `0..num_classes-1` raises `ValueError`. Non-integer dtypes raise `TypeError`. Shape mismatch raises `ValueError`.
- IoU = tp / (tp+fp+fn). F1 = 2tp / (2tp+fp+fn).
- A class absent from both truth and prediction gives NaN for its IoU and F1 and is excluded from the means (`nanmean`). A class present in truth but never predicted scores 0 and is included.
- If no class occurs at all, the means are NaN.
- `LABEL_NODATA` and `NUM_CLASSES` are constants in `metrics.py` (not read from `contracts/classes.yaml`), so the module does not import geopandas or yaml. Keep in sync with the contract if classes change.
