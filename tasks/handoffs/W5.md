**How it works:**
- Three tables (by transition, by from-class, by to-class) with ha and percent. Sortable: each header holds a real `<button>` (Tab, Enter and Space work), `<th aria-sort>` is ascending/descending/none; default sort is area descending.
- Recharts horizontal bar chart of ha by transition, bars filled with the to-class Okabe-Ito hex from the API payload (same palette as `lib/classes.ts`), black outline, every bar labelled on the category axis, so colour is never the only encoding. Wrapped in `role="img"` with a caption pointing to the transitions table as the text equivalent.
- CSV: real API call `GET /changes/{id}/stats` with `Accept: text/csv` (`parseAs: "text"`), saved through a Blob and a temporary anchor (filename `peatwatch-change-<id>.csv`; the server's Content-Disposition name is not readable from a blob download). Failure shows a `role="alert"`.
- Empty: no transitions or `total_ha` 0 shows a status message and no tables or CSV button; all-unchanged data says "No change detected".
