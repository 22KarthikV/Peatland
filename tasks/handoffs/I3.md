**How the script works:**
- Runs from `infra/`, throwaway dir `infra/.smoke-infra` (state via `init -backend-config=path=...`, `TF_DATA_DIR`), removed on exit by the trap. Sets `TF_VAR_api_key=dev-only-key` and dummy `test`/`test` AWS keys.
- Checks go through python urllib straight to `localhost:4566` (override with `LOCALSTACK_ENDPOINT`), no docker and no boto, so it works from any worktree (compose project name differs per worktree) and needs no auth token. It reads `terraform output -json`, then checks the two `-tf` buckets exist, the jobs queue has `VisibilityTimeout=900`, `RedrivePolicy` with `maxReceiveCount=3` targeting the `jobs_dlq_arn` output (and that DLQ exists), and the secret exists.
- The trap always runs `tflocal destroy`, then compares a bucket/queue snapshot taken before and after; any difference or failed destroy makes the script exit 1 with a message.
- Needs `terraform`, `tflocal`, `python` on PATH. The `tflocal` deprecation banner (use `lstk terraform`) is printed by the tool; harmless.
- Note: when invoking from PowerShell use Git's `bash.exe` explicitly; the WSL `bash` on PATH has no distro.

**Recommended CI job steps (`.github/workflows/infra.yml`, no AWS credentials, no OIDC):**
```yaml
jobs:
  terraform:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: infra
    steps:
      - uses: actions/checkout@v4
      - uses: hashicorp/setup-terraform@v3
        with:
          terraform_version: 1.9.x   # any >= 1.6 with mock provider support (>= 1.7)
      - run: terraform fmt -check -recursive
      - run: terraform init -backend=false
      - run: terraform validate
      - run: terraform test
```
Notes: `terraform test` uses mock providers and needs no credentials. Do not run `plan` against dev/prod tfvars in CI (needs AWS and filled network values, see I2 handoff item 5); `docs/infra/plan-evidence.md` records the mock-plan evidence instead. Do not run `smoke_infra.sh` in CI (needs LocalStack with SERVICES=s3,sqs,secretsmanager; optional later job using the `localstack/localstack` service container, `pip install terraform-local`, and the script unchanged).
