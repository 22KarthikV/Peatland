**Design notes:**
- ECR `peatwatch/{api,worker,web}`; ECS cluster; api and worker task definitions reuse `aws_iam_role.api/worker` (so `enable_aws_only` requires `enable_iam`, enforced by a precondition) plus a new `task_execution` role. Tasks in private subnets, no public IP, `user = "app"`, awslogs.
- Env mirrors the compose `api-env` (minus LocalStack endpoint and static keys), plus bucket/queue names and `CORS_ORIGINS` = the CloudFront URL.
- DB: RDS `manage_master_user_password`; ECS injects `DB_USER`/`DB_PASSWORD` from that secret. The app reads one `DATABASE_URL`, so the container command is `sh -c` that builds it (percent-encoded, `sslmode=require`) then `exec`s the compose command (api also runs `alembic upgrade head`, which creates the PostGIS extension).
- ALB: HTTP:80 forwards unless `alb_certificate_arn` is set, then HTTP redirects and HTTPS:443 forwards. Health check `GET /health`.
- CloudFront + private S3 web bucket with OAC; 403/404 serve `/index.html`.
