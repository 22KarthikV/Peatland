# M6 handoff: sliding-window inference and classification COG

Files: `ml/src/ml/infer.py`, `ml/src/ml/cog.py`, `ml/tests/test_inference.py`.

## API
- `ml.infer.ProbaModel` Protocol: `predict_proba(window: (C,h,w) float32) -> (K,h,w)`; K = 4 (channel index = class id). NaN in all channels marks a pixel the model cannot classify (-> 255).
- `HardLabelAdapter(labeller)` one-hot adapter; `ndvi_baseline_model(rules=None)` wraps `classify_array`.
- `predict_cog(src_path, dst_path, model, *, window_size=512, overlap=128)` streams windows, Hann-blends (strictly positive weights), argmax, writes the COG. Memory is O(K * window_size * raster_width). Rasters smaller than the window are handled. Window sizes give identical output for per-pixel models.
- `predict_cog_ndvi(src, dst)` convenience.
- `ml.cog.ClassificationCogWriter` (windowed write, COG built on exit) and `class_colormap()` (Okabe-Ito RGBA from classes.yaml, 255 transparent).

## COG output
uint8, nodata 255, CRS and transform copied from the composite (EPSG:32630, 10 m), GDAL COG driver, 512 tiles, DEFLATE PREDICTOR=2, nearest overviews, embedded colormap, band description `class`, no datetime tags (byte-deterministic, tested).

## Validation
No `rio cogeo` dependency exists and pipeline has no validator helper, so tests use the rasterio equivalent: `IMAGE_STRUCTURE LAYOUT=COG`, tiled 512 blocks, overviews, compression, predictor, colormap, nodata, CRS.

## Notes for others
- A trained model (M5 RF, M8+ U-Net) only needs `predict_proba`; per-window normalisation must be done inside the model.
- Requested changes: none.
