# A7 handoff: classifications, changes, stats, downloads

Routes (all behind `enforce_rate_limit`; `POST /sites/{id}/changes` was already in `JOB_ROUTES`):
- `GET /sites/{id}/classifications` (`routes/classifications.py`): filters `model` (`name` or `name-version`), `year`; paging; ordered by window start. Joins classifications -> composites -> models.
- `POST /sites/{id}/changes` (`routes/changes.py`): resolves model like runs (default model when omitted), requires a composite and classification for both windows (`422 classification_missing`, detail `{year, season, model, window}`), `from` must start before `to` (`422 validation_error`, loc `body.from`). Existing change for (from, to, model) -> `200 Change`. Otherwise creates a `kind=change` run (outputs preset to `{composite_ids:[],classification_ids:[],change_id:null}`), commits, then sends the queue message (validated against queue.schema.json in tests). An identical active run is returned with `202` (per openapi, unlike runs which use 200).
- `GET /changes/{id}/stats`: `Accept` negotiation (json default, `*/*`, `text/csv`, q-values); others `406 not_acceptable`. Built from the `changes.stats` jsonb column (db-schema shape), not from the store; CSV is generated from the same rows (sorted by from, to; 2-dp) with `Content-Disposition: attachment; filename="<site>-<y1>-<s1>__<y2>-<s2>-<model>-<ver>.csv"`. `stats_csv_uri` is not read.
- No `GET /changes/{id}` and no separate download endpoint: openapi.yaml has neither. Download links are `download_url` (presigned GET, 900 s) on Classification/Change products.

Storage: `ObjectStore.presign_get(bucket, key, expires_seconds=900)` added; `S3ObjectStore` uses boto3 `generate_presigned_url` (local signing, needs credentials); `InMemoryObjectStore` returns a deterministic localhost:4566 URL and honours `fail`.

Status codes not in openapi.yaml: `503 storage_unavailable` (presign failure; also on stats JSON since it embeds the Change) and `503 enqueue_failed` (same as runs).

Notes / for the orchestrator:
- `tile_url` base comes from env `TITILER_BASE_URL` (default `http://localhost:8001`); no Settings field because settings.py was out of scope. Presigned URLs use `AWS_ENDPOINT_URL` host, so in docker they carry the internal host unless a public endpoint is configured (A8/infra concern).
- Class table is duplicated in `routes/classifications.py::CLASSES` (no runtime path to classes.yaml); `test_classes_match_contract` guards drift.
- Class-area percents are computed from the stored hectares (classifications: share of their sum; change: share of `total_ha`).
- Response models with `class`/`from` use pydantic aliases; two `# type: ignore[call-arg]` for mypy on alias kwargs.
- `_parse_accept`, `canonical`, `_resolve_model` etc. are reused from runs.py via import.
