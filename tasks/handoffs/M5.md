# M5 handoff: random-forest baseline

Files: `ml/src/ml/baseline_rf.py`, `ml/tests/test_baseline_rf.py`.

## API
- `sample_pixels(patches, *, max_samples=200_000, seed=0) -> (X (n, 18), y)`: class-balanced (cap `max_samples // n_present_classes` per class), seeded. Keeps only pixels with a class-id label (not 255), `patch.valid`, and all bands finite.
- `train_rf(ds, split_result, *, split="train", max_samples, seed, n_estimators=100, max_depth=None, min_samples_leaf=1, n_jobs=1, **rf_kwargs) -> RandomForestBaseline`. `ds` must be built with `normalize=None`, `nan_policy="keep"` and labels (ValueError otherwise). Features are the raw 18 bands, same as the NDVI baseline.
- `RandomForestBaseline`:
  - `__call__(patch) -> (H, W) uint8` works as an `ml.evaluate` predictor (255 where any band is non-finite or patch invalid).
  - `predict_proba((C, h, w)) -> (4, h, w)` satisfies `ml.infer.ProbaModel` (NaN in all channels for non-finite pixels, so `predict_cog` writes 255). Classes absent from training get probability 0.
  - `save(path)` / `load_model(path)` via joblib (stores the sklearn `RandomForestClassifier`).
- Example: `evaluate(train_rf(ds, split), ds, split)` then `write_metrics_json(...)`; `predict_cog(src, dst, model)`.

## Notes
- Deterministic for a fixed `seed` (sampling and forest `random_state`; tested).
- joblib files are pickles: only load trusted models. Model files depend on the scikit-learn version.
- Real-data metrics not produced here (no labelled data in the sandbox); run through the harness once L-tasks deliver labels.
- No new dependencies (scikit-learn and joblib already in `ml/pyproject.toml`). Requested changes: none.
