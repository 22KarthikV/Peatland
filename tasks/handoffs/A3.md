**Decisions / gotchas:**
- **Status code is 422, not 400.** `contracts/openapi.yaml` declares `boundary_invalid` / `boundary_outside_region` / `boundary_too_large` / `validation_error` under 422 (no 400 declared) and the fixture is `error.422.boundary_too_large.json`, so I followed the contract. Body is `{code, message, detail}` via `ApiError`. Duplicate slug is 409 `conflict`, unknown id 404, malformed uuid 422 `validation_error`.
- **Supported region** has no coordinates in contracts. Derived from MGRS: zone 30, squares U/V = eastings 300-500 km, rows F/G = northings 6000-6200 km (EPSG:32630), plus the 4.9 km S2 tile overlap margin per side, i.e. envelope (295100, 5995100)-(504900, 6204900) in EPSG:32630 (`validation.REGION_BOUNDS_M`). Checked in PostGIS (`ST_Within` after transform to 32630), so no pyproj needed. The boundary must be entirely inside (partial overlap rejected). Replace the envelope if an exact tile-union polygon is wanted.
- Area uses `ST_Area(ST_Transform(g, 32630)) / 10000`, same as generated `sites.area_ha`. Max is `validation.MAX_SITE_AREA_HA = 50000` (module constant; `settings.py` was out of scope). Check order: valid, region, area.
- Insert uses `ST_Multi(ST_GeomFromText(wkt, 4326))` explicitly. Shapely rejects invalid polygons before the DB (`ST_IsValid` check constraint is the backstop). Accepts Polygon, MultiPolygon or Feature.
- `boundary_sha256` is the SHA-256 of canonical GeoJSON of the MultiPolygon; `boundary_uri` = `s3://<data_bucket>/sites/<slug>/boundary.geojson`. **The file is NOT uploaded to S3 here** (no storage module exists yet). Whoever uploads it must write exactly `json.dumps(mapping(multipolygon), separators=(",", ":"), sort_keys=True)` (see `routes/sites.py`) or the hash will not match. Needs an owner (A5, worker or a storage helper).
- Slug is derived from name when omitted (lowercase, non-alnum to `-`); if nothing usable results, 422 `validation_error` asks for `slug`. A derived-slug collision returns 409 (no auto-suffix).
- GET /sites: `limit` 1-200, `offset`, `q` (case-insensitive substring of name/slug, LIKE wildcards escaped), newest first, `latest_run` = most recent run of any kind (DISTINCT ON). GET /sites/{id}: `available_windows` from composites oldest first, with `<name>-<version>` model strings from classifications.
